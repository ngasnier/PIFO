Class: WGRIBTextFieldDataSource

WGRIBTextFieldDataSource() → {undefined}

Source de données basée sur les fichiers textes issus de WGRIB.

C'est le format de données historique du projet PIFO. Il est composé de :

  • un fichier fileinfo.txt : format CSV, décrit les méta-données de base telles que l'heure d'init du modèle, le nom du modèle et la liste des enregistrements temporels sous forme de nombre d'heures depuis le début de la simulation et la liste des fichiers le constituant.
  • des fichiers textes au format WGRIB : un ou plusieurs fichiers par enregistrement temporel (un par niveau), sous la forme NOM_hhh.txt ou NOM_n_hhh.txt. n = numéro de niveau commençant à zero, hhh le nombre d'heures depuis le début de la simulation.

La source utilise AJAX en navigateur, ou fs sous node, pour le chargement des données.
