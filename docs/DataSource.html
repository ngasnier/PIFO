Définition de l'interface d'une source de données de variables pour le modèle.

Une source de données fournit un catalogue de variables. Les variables sont des tableaux 2D ou 3D de données, plus une dimension temporelle. (NDLA : il faudra probablement adapter certaines choses pour faciliter une utilisation du format NetCDF dans le futur)
