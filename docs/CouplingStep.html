Class: CouplingStep

CouplingStep() → {undefined}

Fournit au modèle des variables de couplage interpolées temporellement.

L'objet utilise la dimension temporelle des variables pour déterminer les données à charger en fonction de la propriété time du modèle. Une interpolation linéaire des données est appliquée entre deux points temporels.

Paramètres :

  • dataSource : une référence de DataSource.
  • variables : un tableau de mappage de variables sous la forme : {name:"variable", source:"nom_dans_DataSource"}
